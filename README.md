# 初婚年龄十年曲线：婚姻推迟背后的城市成本结构

> 交互式数据新闻作品 | Interactive Data Journalism Special Report

## 项目简介

多地初婚年龄逼近或突破 30 岁。“不敢结婚”不仅是情感问题，更是一本可量化的经济账。本项目汇集国家统计局人口普查数据、民政部历年统计公报、地方民政部门官方通报及权威智库研究报告，通过沉浸式滚动叙事（Scrollytelling）解构婚姻推迟背后的居住成本、育儿直接支出与职场工时挤压。

## 技术栈

- **前端架构**：HTML5 + Tailwind CSS
- **数据可视化**：Apache ECharts 5.5
- **滚动叙事与动效**：GSAP 3 + ScrollTrigger
- **图标系统**：Lucide Icons

## 权威数据信源

1. **国务院第七次全国人口普查领导小组办公室、国家统计局**：《中国人口普查年鉴-2020》（第五卷《婚姻》）
2. **中华人民共和国民政部**：《2013—2024年民政事业发展统计公报》
3. **地方民政部门婚姻登记通报**：上海市民政局、杭州市民政局、江苏省民政厅、安徽省民政厅
4. **育娲人口研究智库**：《中国生育成本报告2024版》（基于国家统计局住户调查数据核算）
5. **诸葛数据研究中心 & 麟评居住大数据研究院**：《2024上半年重点50城租金收入比报告》《2024百城房价收入比报告》
6. **国家统计局 & 智联招聘**：《全国企业就业人员周平均工作时间》《2024中国女性职场现状调查报告》

## 本地运行

直接双击打开 `index.html`，或在项目根目录下启动任意静态服务器：

```bash
python3 -m http.server 8080
```
随后在浏览器访问 `http://localhost:8080`。
